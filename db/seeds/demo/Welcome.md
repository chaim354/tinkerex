# Welcome to the Tinkerex demo

This is a shared demo account: everyone who clicks **Try the demo** lands in this same library, so
nothing you do here is private. Every night at 04:00 UTC the whole library is wiped and put back
exactly as you first found it.

Things to try:

- Open **Projects**, then **catan**: a maker's real laser-cut board-game set, the hex tiles, tokens,
  cards and game box in LightBurn, SVG and DXF, a MillMage file for the CNC, and the robber to
  print. It is the project the tinkerex.com front page shows.
- Open **Projects**, then **Desk Lamp**. The project page lists its folder, renders its README and
  links the parts.
- Open `Projects/Desk Lamp/models/base.stl` to turn the part in 3D and measure it.
- Open `Projects/Desk Lamp/pcb/gerber-export.zip` to see the board's layers, and `lamp.kicad_sch`
  beside it for the schematic viewer.
- Open `Laser/bezier-circle.lbrn2` to see a LightBurn file drawn and measured without LightBurn.
- Upload a file of your own. Drop it into the Desk Lamp folder and it is filed by type: an SVG
  lands in `design/`, a photo in `images/`.

The demo account can't change its email or password, publish a project, or sign in a desktop
client. Everything else works the way it does on your own server.
