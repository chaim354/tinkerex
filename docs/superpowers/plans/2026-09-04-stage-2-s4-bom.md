**Goal:** Deliver S2-4 of `docs/superpowers/specs/2026-09-04-stage-2-structure-design.md` (§7): a **BOM panel** on the project page below Tasks, and a full page at `/projects/:id/bom`. Lines show their target kind as a badge (stock / file / text), quantity and unit, supplier, and for stock lines the on-hand position; a rollup line totals them; an Add-line composer takes exactly one of three targets; **Consume** on a stock line posts a `consumed` transaction against the project through `Maker::InventoryTransaction.apply!`. **Architecture:** One BOM per project on the web — the **latest revision** (`project.boms.order(revision: :desc, id: :desc).first`), created lazily (`name: "BOM", revision: 1`) by the first line's POST and **never by a GET**. `Projects::BomLinesController` (create / destroy / consume) and `Projects::BomsController#show` on the existing `Maker::Bom` / `Maker::BomLine` models (routes already drawn: `project_bom_path(project)`, `project_bom_lines_path(project)`, `bom_line_path(line)`, `consume_bom_line_path(line)`). A small `Maker::BomRollup` PORO computes the totals both surfaces show. The panel and the page render one shared partial.

**Tech Stack:** Rails 8, Hotwire (plain forms + redirects, as the Tasks panel's no-JS path), Minitest request tests, `page_query_budget_test.rb`.

### Task B: `Maker::BomRollup`

```ruby
module Maker
  # The totals a bill of materials shows (stage 2, S2-4), computed once over lines the caller has
  # ALREADY LOADED with their inventory items — this class issues no query, so it cannot become the
  # per-line read page_query_budget_test.rb forbids.
  class BomRollup
    Short = Data.define(:line, :on_hand)

    attr_reader :lines

    def initialize(lines)
      @lines = lines.to_a
    end

    def count = lines.size
    def by_kind = @by_kind ||= lines.group_by(&:target_kind).transform_values(&:size)   # { inventory_item: 3, design_file: 1, free_text: 1 }
    def stock_count = by_kind.fetch(:inventory_item, 0)
    def file_count = by_kind.fetch(:design_file, 0)
    def text_count = by_kind.fetch(:free_text, 0)

    # Sum of quantity × the item's unit_cost over stock lines whose item HAS a cost; nil when no line
    # is costed, so a view can say nothing rather than "$0.00".
    def estimated_cost
      costed = lines.select { |l| l.target_kind == :inventory_item && l.inventory_item&.unit_cost }
      return nil if costed.empty?
      costed.sum { |l| l.quantity * l.inventory_item.unit_cost }
    end

    # Stock lines whose item's cached balance is below the line's quantity — what a build cannot
    # start with. A dangling item (deleted; the line is text by then) never appears here.
    def short
      lines.filter_map do |l|
        next unless l.target_kind == :inventory_item && l.inventory_item
        on_hand = l.inventory_item.quantity_cached
        Short.new(line: l, on_hand:) if on_hand < l.quantity
      end
    end
  end
end
```

Tests (`test/services/maker/bom_rollup_test.rb`, fixtures via `User.create!`, a project, a bom, lines of each kind — a stock line needs an inventory item with `unit_cost` and a balance via `InventoryTransaction.apply!`): counts by kind; `estimated_cost` sums only costed stock lines and is nil with none; `short` lists the stock line whose balance is below quantity and not the one at or above it; an empty BOM answers zeros and nil; **no query** is issued by any reader when the lines were loaded with `includes(:inventory_item)` (use the `count_queries` idiom from `library_tree_test.rb`). Mutation: make `short` compare with `<=` → the "at quantity is not short" case fails. Commit with a pathspec: `Maker::BomRollup: the totals a BOM shows, from lines already loaded`.

```ruby
module Projects
  # The bill of materials' three doors (stage 2, S2-4). Session-authed; the same models the v1
  # BomLines API writes. ONE bom per project on the web: the latest revision, created here by the
  # first line and never by a reader. Consume is the ledger's one door, apply!, with the project.
  class BomLinesController < ApplicationController
    PANEL_CAP = 8
    TARGETS = %w[stock file text].freeze

    def create
      project = current_user.maker_projects.find_by!(slug: params[:project_id])
      attrs = line_params.to_h.symbolize_keys
      kind = params.dig(:bom_line, :target_kind).to_s
      return back_to(project, alert: "Pick what the line points at: stock, a file, or a part name.") unless TARGETS.include?(kind)
      # EXACTLY ONE TARGET, CHOSEN BY THE RADIO: the other two inputs are dropped here so a filled-in
      # but unchosen field can never make the model's exactly_one_target refuse a line the user meant.
      attrs[:inventory_item_id] = nil unless kind == "stock"
      attrs[:node_id] = nil unless kind == "file"
      attrs[:part_name] = nil unless kind == "text"
      case kind
      when "stock" then return back_to(project, alert: "Pick a stock item.") if attrs[:inventory_item_id].blank?
      when "file"
        node = current_user.nodes.present.find_by(node_id: attrs[:node_id], kind: "file")
        return back_to(project, alert: "That file isn't in your library.") unless node
      when "text" then return back_to(project, alert: "Enter a part name.") if attrs[:part_name].blank?
      end
      bom = Maker::Bom.transaction { latest_bom(project) || project.boms.create!(user: current_user) }
      line = bom.lines.new(attrs.merge(user: current_user, position: (bom.lines.maximum(:position) || -1) + 1))
      if line.save then back_to(project, notice: "Added #{line_label(line)}.")
      else back_to(project, alert: line.errors.full_messages.to_sentence) end
    end

    def destroy ... current_user.maker_bom_lines.find(params[:id]) ... back_to(line.bom.project, notice: "Removed #{label}.")

    def consume
      line = current_user.maker_bom_lines.includes(:inventory_item, bom: :project).find(params[:id])
      project = line.bom.project
      item = line.inventory_item if line.target_kind == :inventory_item
      return back_to(project, alert: "Only a stock line can be consumed.") unless item
      Maker::InventoryTransaction.apply!(item:, user: current_user, delta: -line.quantity, reason: "consumed",
                                         project_id: project.id, note: "BOM: #{line_label(line)}")
      back_to(project, notice: "Consumed #{fmt(line.quantity)} #{item.unit} of #{item.name} for #{project.name}.")
    end

    private
    def line_params = params.require(:bom_line).permit(:reference, :quantity, :unit, :inventory_item_id, :node_id, :part_name, :supplier_id, :notes)
    def back_to(project, **flash) = redirect_back_or_to(project_path(project), **flash)
  end
end
```
