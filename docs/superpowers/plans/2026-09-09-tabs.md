# Tabs Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking. **In this repo `.claude/commands/execute-plan.md` overrides the generic loop:** batch by file (the four tasks below are already batched), no spec-compliance stage, one capped quality review per task, every guard mutation-checked with its red output recorded.

**Goal:** A maker groups the panels below an always-visible top group into named tabs, from the same editor, in the same flat order, with the same YAML — and a project without tabs renders exactly as it does today.

**Architecture:** A tab is a separator entry `tab:<12-hex key>` in the layout's `order` list, named in the existing `titles` map (spec `docs/superpowers/specs/2026-09-09-tabs-design.md`, decision 2). `Maker::ProjectKind.layout_for` reads tab keys off the stored order into the vocabulary; `Layout#groups` splits a key list into the top group and the tabs; one layout partial renders that shape for the maker's page and the visitor's page; `Maker::LayoutDocument` gains a `tab` entry in the draft and `- tab: Name` + `id:` in the YAML; Save rekeys `tab:new-N` like a block; the editor renders a separator slot per tab key and a `tabs` Stimulus controller shows one pane at a time on the read pages.

**Tech Stack:** Rails 8 views and services, Minitest (three `LIBRARY_BACKEND` legs), Stimulus + SortableJS, Capybara/Selenium system tests.

**Spec:** `docs/superpowers/specs/2026-09-09-tabs-design.md` (approved 2026-09-09). Read §3 to §7 before Task A.

**Branch:** `claude/tabs`, already holding the spec (4861d37). Every commit: `git commit -F <message file> -- <paths>`, never `git add -A`; a NEW file needs an explicit `git add <path>` first. Run every repo-editing Ruby script as `LANG=en_US.UTF-8 ruby -Eutf-8:utf-8`. Bare `bin/rails test` needs `LIBRARY_BACKEND=share LIBRARY_PATH=$(mktemp -d)` in this environment.

In `app/services/maker/project_kind.rb`, after `BLOCK_DEFAULT_WIDTHS` (line ~213):

```ruby
    # `tab:<key>` — a SEPARATOR in the flat order (2026-09-09, tabs; spec §3 and decision 2). Twelve
    # hex characters minted on Save, like a block's, but there is NO ROW: the key's presence in the
    # stored order IS the tab, and its name is the `titles` entry under it. A tab has no width, no
    # view, no intro and cannot be hidden — hide its panels, and a tab with nothing to show is not
    # rendered. TAB_KEY is what #tab_keys_in reads off a stored order; a browser placeholder
    # (`tab:new-1`) or a truncated key is never vocabulary.
    TAB_PREFIX = "tab:".freeze
    TAB_KEY = /\Atab:[0-9a-f]{12}\z/
    TAB_CAP = 8
    TAB_NAME_MAX = 30
    TAB_FALLBACK_NAME = "Tab".freeze
    NEW_TAB_KEY = /\Atab:new-\d+\z/

    # What the pages render from (spec §3): the keys before the first tab, then one Tab per
    # separator with the keys up to the next one. `publish` is in neither — it is pinned below the
    # tabs (decision 3) and the pages render it themselves.
    Tab = Data.define(:key, :name, :slug, :keys)
    Groups = Data.define(:top, :tabs)
```

Extend the `Layout` struct (inside the `Data.define(...) do` block, after `block_kind`):

```ruby
      def tab?(key) = key.to_s.start_with?(TAB_PREFIX)
      def tabs = order.select { |k| tab?(k) }
      # TOTAL: a tab key with no title (a column written by hand) reads as "Tab", never as nil in a
      # heading — the writers (Maker::LayoutDocument) never store a blank one.
      def tab_name_for(key) = titles[key.to_s] || TAB_FALLBACK_NAME

      # THE ONE GROUPING READER for the maker's page and the visitor's (spec §3, §6). `keys` is
      # `visible` for a page and `order` for every group hidden panels included; whichever it is,
      # `publish` is dropped here because the pages pin it below the tabs, and hidden TAB keys do
      # not exist (layout_for drops them from `hidden`). Slugs come from the names; see .tab_slugs.
      def groups(keys = visible)
        top, found = [], []
        keys.each do |k|
          next if k == "publish"
          if tab?(k) then found << [ k, [] ]
          elsif found.empty? then top << k
          else found.last.last << k
          end
        end
        names = found.map { |k, _| tab_name_for(k) }
        slugs = ProjectKind.tab_slugs(found.map(&:first), names)
        Groups.new(top:, tabs: found.each_with_index.map { |(k, ks), i| Tab.new(key: k, name: names[i], slug: slugs[i], keys: ks) })
      end
```

After `def self.block_key` (line ~265):

```ruby
    def self.tab_key(key) = "#{TAB_PREFIX}#{key}"
    def self.new_tab_key = SecureRandom.hex(6)

    # THE TAB KEYS A STORED ORDER CARRIES, in order, deduplicated, and CAPPED HERE so the read is
    # total: a ninth tab key is not vocabulary, so `known` drops it and its panels join the group
    # before it (spec §3). A browser's `tab:new-N` placeholder never matches TAB_KEY.
    def self.tab_keys_in(list) = Array(list).map(&:to_s).select { |k| k.match?(TAB_KEY) }.uniq.first(TAB_CAP)

    # A TAB'S PLACE IN A URL: `#tab-<slug>`, the parameterized name (spec §3). A name that
    # parameterizes to nothing, or two names that collide ("Build!" and "build?"), fall back to the
    # key — EVERY colliding tab, not the second one alone, because "which one keeps the pretty slug"
    # is an order-dependent answer that a rename elsewhere on the page would flip.
    def self.tab_slugs(keys, names)
      base = names.map { |n| n.to_s.parameterize }
      keys.each_with_index.map do |key, i|
        s = base[i]
        s.empty? || base.count(s) > 1 ? key.to_s.delete_prefix(TAB_PREFIX) : s
      end
    end
```

```js
import { Controller } from "@hotwired/stimulus"

// ONE PANE AT A TIME (2026-09-09, tabs; spec §6). The server renders every pane with its heading and
// a bar of ordinary anchors, so without this controller the page reads as sections and nothing is
// hidden (decision 8). This adds `tabs-ready` (the sheet hides the headings under it), shows one
// pane and marks one tab selected, and answers three ways in: a hash naming a pane (`#tab-build`),
// a hash naming an element INSIDE a pane (`#tasks`, a panel's anchor — the head's links keep
// working), and a click, which rewrites the hash with replaceState so a tab is shareable without a
// history entry per click. Left/Right/Home/End follow the ARIA tabs pattern with a roving tabindex.
//
// A HIDDEN PANE MEASURES ZERO, and masonry_controller's ResizeObserver reports the change when a
// pane is shown, so the pane re-packs on its own; nothing here talks to it.
export default class extends Controller {
  static targets = ["tab", "pane"]

  connect() {
    this.element.classList.add("tabs-ready")
    this.onHash = () => this.showFromHash(false)
    window.addEventListener("hashchange", this.onHash)
    this.showFromHash(true)
  }

  disconnect() {
    window.removeEventListener("hashchange", this.onHash)
    this.element.classList.remove("tabs-ready")
    this.paneTargets.forEach((p) => { p.hidden = false })
  }

  select(event) {
    event.preventDefault()
    this.show(this.tabTargets.indexOf(event.currentTarget), true)
  }

  key(event) {
    const i = this.tabTargets.indexOf(event.currentTarget)
    const last = this.tabTargets.length - 1
    const next = { ArrowRight: i === last ? 0 : i + 1, ArrowLeft: i === 0 ? last : i - 1, Home: 0, End: last }[event.key]
    if (next === undefined) return
    event.preventDefault()
    this.show(next, true)
    this.tabTargets[next].focus()
  }

  showFromHash(initial) {
    const hash = decodeURIComponent(window.location.hash.slice(1))
    let i = hash ? this.paneTargets.findIndex((p) => p.id === hash) : -1
    let target = null
    if (i < 0 && hash) {
      const el = document.getElementById(hash)
      const pane = el?.closest(".tab-pane")
      if (pane) { i = this.paneTargets.indexOf(pane); target = el }
    }
    // A HASH THAT NAMES NOTHING HERE (a stale slug after a rename, a hidden panel, #publish): the
    // first tab on load, and no change on a later hashchange.
    if (i < 0) { if (!initial) return; i = 0 }
    this.show(i, false)
    if (target) requestAnimationFrame(() => target.scrollIntoView())
  }

  show(i, write) {
    this.tabTargets.forEach((t, j) => {
      const on = i === j
      t.setAttribute("aria-selected", String(on))
      t.tabIndex = on ? 0 : -1
      t.classList.toggle("is-active", on)
    })
    this.paneTargets.forEach((p, j) => { p.hidden = i !== j })
    if (write) history.replaceState(null, "", `#${this.paneTargets[i].id}`)
  }
}
```
