> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking. `.claude/commands/execute-plan.md` governs batching: Tasks 1–3 touch disjoint files and run in parallel in their own worktrees; Task 4 is the orchestrator's.

**Goal:** A visitor to tinkerex.com clicks **Try the demo**, lands in a shared account seeded with sample files and a project, can do everything a maker does except escape the sandbox, and finds it reset the next morning. Design: `docs/superpowers/specs/2026-10-14-h-public-demo-design.md`.
