> **For agentic workers:** execute with **`/execute-plan`** (`.claude/commands/execute-plan.md`,

**Goal:** On tinkerex.com, `/` becomes a real landing — a headline, Try the demo, a wall of twelve of
the app's own renders, how it works, four feature rows with crops, a self-hosting band — while every
other deployment's signed-out `/` becomes the plain sign-in card.

**Spec:** `docs/superpowers/specs/2026-10-16-landing-format-wall-design.md` (read it first).

**Architecture:** A request-time route constraint on demo mode (`Tinkerex::Landing.enabled?`) sends
signed-out `/` to `LandingsController` (on `ActionController::Base`, outside the
`authenticate_user!` tree) or to Devise's sign-in. `Tinkerex::Landing` owns the twelve tiles and
renders them through `Maker::Previews::Registry` — whose `available_for?`/`render` move there from
`GeneratePreviewJob` so both callers render identically — into committed PNGs. The sample files
behind the tiles live in `db/seeds/demo`, generated by a CadQuery script, so the demo a visitor
clicks into holds the same files.

**Tech stack:** Rails 8, ERB, Propshaft, layered CSS (`@layer pages`), Minitest + Capybara/Selenium,
Python 3.12 + CadQuery 2.8 (author-only, never shipped), Docker (linux/amd64 production image).

```ruby
      # IS THIS RENDERER ABLE TO BUILD **THIS KIND** ON THIS BOX? Asked by GeneratePreviewJob before
      # every render and by Tinkerex::Landing before every wall tile -- one answer, so the landing
      # can never show a tile the library would have marked `unsupported`.
      #
      # `available?` asks about the TOOLCHAIN, and for the 2D vector formats that toolchain is resvg
      # — because their THUMBNAIL is a rasterized SVG. The Measure payload from the same renderers is
      # Nokogiri and arithmetic and needs nothing external, so a single `available?` gate marks a
      # perfectly measurable .svg/.dxf/.lbrn2 `unsupported` on any box without the rasterizer. That
      # reads to a user as "we cannot handle this file", which is false, and it would have made the
      # measure feature silently backend-dependent: `Mage.available?` is unconditionally true, so
      # .mage would measure on such a box while the other three did not.
      #
      # `respond_to?` WITH A FALLBACK TO `available?`, the same shape `Enqueue.revision_for` already
      # uses for `payload_revision` — so the ten renderers that produce only a thumbnail are
      # untouched and the registry's published contract (available?/render/EXTENSIONS) still holds.
      def available_for?(renderer, kind)
        return renderer.available_for?(kind) if renderer.respond_to?(:available_for?)

        renderer.available?
      end

      # Renderers share a `render(bytes, size:)` contract; some (e.g. Mesh/F3D) also accept
      # `ext:` (to pick the loader) and `kind:`. Accepting `kind:` is not a promise to produce
      # every kind — Mesh takes it only to REFUSE `model_glb` (f3d renders rasters and cannot
      # export GLB), raising Unsupported, which GeneratePreviewJob maps to that terminal status.
      # Pass each kwarg only when the renderer's signature declares it, so the simpler
      # renderers stay unchanged.
      def render(renderer, bytes, ext:, kind:, size: 512)
        accepted = renderer.method(:render).parameters.select { |t, _| %i[key keyreq].include?(t) }.map(&:last)
        opts = { size: }
        opts[:ext]  = ext  if accepted.include?(:ext)
        opts[:kind] = kind if accepted.include?(:kind)
        renderer.render(bytes, **opts)
      end
```

```ruby
  # Tinkerex::Demo is: a test flips the variable between requests.
  #
  # THE WALL IS RENDERED, NEVER DRAWN. Each tile is the app's own preview of one file in the demo
  # seed, so the picture a stranger sees is the picture the library draws for that file, and the demo
  # they click into holds the same files. `render_wall` runs every tile's source through
  # Maker::Previews::Registry -- the calls GeneratePreviewJob makes -- and writes the PNGs the view
  # serves. It REFUSES rather than skips (a missing source, an extension no renderer claims, a
  # toolchain absent on this machine, a non-PNG result), and it writes NOTHING unless every tile
  # rendered: a wall with a hole in it, or one tile left over from an older run, is the failure to
  # fear. `bin/rails "landing:wall"` is the door; the recipe with every toolchain is Task 4 of

    Error = Class.new(StandardError)

    INSTALL_URL = "https://github.com/chaim354/tinkerex/blob/main/docs/INSTALL.md".freeze
    SOURCE_URL = "https://github.com/chaim354/tinkerex".freeze

    # A `photo` is a camera picture: the wall crops it to fill its square on the photo stage, where a
    # render keeps `contain` on the white thumb stage (design-system.md rule 5).
    Tile = Data.define(:source, :alt, :photo) do

    # Renders every tile, THEN writes them all, so a refusal leaves the wall as it was.
    def self.render_wall(seed_dir: SEED_DIR, out_dir: OUT_DIR, tiles: TILES, size: SIZE)
      rendered = tiles.map { |tile| [ tile, render_tile(tile, seed_dir: Pathname(seed_dir), size:) ] }
      out_dir = Pathname(out_dir)
      out_dir.mkpath
      rendered.map { |tile, bytes| out_dir.join("#{tile.ext}.png").tap { |path| path.binwrite(bytes) } }

    def self.render_tile(tile, seed_dir:, size:)
      path = seed_dir.join(tile.source)
      raise Error, "#{tile.source} is not in #{seed_dir}" unless path.file?

      renderer = Maker::Previews::Registry.for_filename(path.basename.to_s)
      raise Error, "no preview renderer claims #{tile.source}" if renderer.nil?

    end
```

```ruby
# The landing's format wall (Tinkerex::Landing): every tile rendered from db/seeds/demo through the
# library's own preview renderers. Needs every renderer's toolchain -- the production image built for
# linux/amd64 has them all (docs/superpowers/plans/2026-10-16-landing-format-wall.md, Task 4).
namespace :landing do
  desc 'Render the landing\'s twelve wall tiles: bin/rails "landing:wall[SEED_DIR,OUT_DIR]" (both optional)'
  task :wall, %i[seed_dir out_dir] => :environment do |_task, args|
    paths = Tinkerex::Landing.render_wall(seed_dir: args[:seed_dir].presence || Tinkerex::Landing::SEED_DIR,
                                          out_dir: args[:out_dir].presence || Tinkerex::Landing::OUT_DIR)
    paths.each { |path| puts "wrote #{path} (#{path.size} bytes)" }
  rescue Tinkerex::Landing::Error => e
    abort "landing:wall: #{e.message}"
  end
end
```

```python
#!/usr/bin/env python3
"""The demo seed's sample files, generated: the files behind the landing's format wall.

docs/superpowers/specs/2026-10-16-landing-format-wall-design.md section 3. Writes, under the seed
directory given (default db/seeds/demo):

  Projects/Desk Lamp/models/base.stl        CadQuery solid, binary STL
  Projects/Desk Lamp/pcb/gerber-export.zip  RS-274X layers and an Excellon drill file, by hand
  Projects/Desk Lamp/docs/assembly.pdf      a one-page drawing, by hand
  Projects/Desk Lamp/firmware/lamp.ino      an Arduino sketch
  Models/knob.3mf                           CadQuery solid
  Models/bracket.step                       CadQuery solid
  Models/cable-clip.obj                     CadQuery solid, tessellated into OBJ here
  Laser/box-side.lbrn2                      LightBurn XML, by hand
  Laser/coaster.svg                         SVG with fills, by hand
  Laser/mount-plate.dxf                     DXF entities, by hand
  CNC/drawer-label.mage                     MillMage XML, by hand

Run it by hand, never from the app, the image or CI. CadQuery is Apache-2.0 and its OCCT binding is
LGPL; both stay on the machine that runs this, and only the files it writes are committed -- the
posture CLAUDE.md section 9 takes for every tool used but not shipped:

  python3.12 -m venv "$SCRATCH/cq" && "$SCRATCH/cq/bin/pip" install cadquery==2.8.0
  "$SCRATCH/cq/bin/python" script/landing/make_samples.py db/seeds/demo

Each file has a byte ceiling below, and the whole seed must stay under demo_reset_test.rb's 200 KB
(the reset writes it through the port every night). A ceiling that trips is fixed by coarsening the
tessellation or the pattern here, never by raising the test's budget unasked.
"""
import math
import sys
import zipfile
from io import BytesIO

import cadquery as cq

OUT = Path(sys.argv[1] if len(sys.argv) > 1 else "db/seeds/demo")

LIMITS = {
    "Projects/Desk Lamp/models/base.stl": 40_000,
    "Projects/Desk Lamp/pcb/gerber-export.zip": 6_000,
    "Projects/Desk Lamp/docs/assembly.pdf": 6_000,
    "Projects/Desk Lamp/firmware/lamp.ino": 3_000,
    "Models/knob.3mf": 20_000,
    "Models/bracket.step": 30_000,
    "Models/cable-clip.obj": 18_000,
    "Laser/box-side.lbrn2": 10_000,
    "Laser/coaster.svg": 6_000,
    "Laser/mount-plate.dxf": 8_000,
    "CNC/drawer-label.mage": 6_000,
}


def check(rel):
    size = (OUT / rel).stat().st_size
    if size > LIMITS[rel]:
        sys.exit(f"{rel} is {size} bytes, over its {LIMITS[rel]}-byte ceiling: coarsen it in make_samples.py")
    print(f"{size:>7}  {rel}")


def put(rel, data):
    path = OUT / rel
    path.parent.mkdir(parents=True, exist_ok=True)
    path.write_bytes(data.encode("utf-8") if isinstance(data, str) else data)
    check(rel)


def export(workplane, rel, **options):
    path = OUT / rel
    path.parent.mkdir(parents=True, exist_ok=True)
    cq.exporters.export(workplane, str(path), **options)
    check(rel)


def rounded_rect(x, y, w, h, r, seg=6):
    """A rounded rectangle as a closed polyline, counter-clockwise from the bottom-right corner."""
    pts = []
    for cx, cy, start in ((x + w - r, y + r, -90), (x + w - r, y + h - r, 0), (x + r, y + h - r, 90), (x + r, y + r, 180)):
        for k in range(seg + 1):
            a = math.radians(start + 90 * k / seg)
            pts.append((cx + r * math.cos(a), cy + r * math.sin(a)))
    return pts


# --- solids (CadQuery) ------------------------------------------------------------------------

def lamp_base():
    foot = cq.Workplane("XY").circle(45).extrude(6).faces(">Z").edges().fillet(2.5)
    neck = cq.Workplane("XY").workplane(offset=6).circle(30).workplane(offset=28).circle(14).loft(combine=True)
    collar = cq.Workplane("XY").workplane(offset=34).circle(16).extrude(8).faces(">Z").edges().chamfer(1)
    bore = cq.Workplane("XY").circle(5).extrude(42)
    channel = cq.Workplane("XY").center(25, 0).rect(42, 7).extrude(3)  # the cable's way out under the foot
    return foot.union(neck).union(collar).cut(bore).cut(channel)


def knob():
    pts = []
    for i in range(48):
        r = 15.0 if i % 2 == 0 else 14.2
        a = 2 * math.pi * i / 48
        pts.append((r * math.cos(a), r * math.sin(a)))
    body = cq.Workplane("XY").polyline(pts).close().extrude(12)
    cap = cq.Workplane("XY").workplane(offset=12).circle(13.5).extrude(4).faces(">Z").edges().fillet(1.5)
    groove = cq.Workplane("XY").workplane(offset=15).center(0, 7.5).rect(1.6, 8).extrude(1)
    d_shaft = cq.Workplane("XY").circle(3.1).extrude(10).cut(cq.Workplane("XY").center(0, 3.1).rect(8, 2.2).extrude(10))
    return body.union(cap).cut(groove).cut(d_shaft)


def bracket():
    part = cq.Workplane("XY").box(44, 26, 5, centered=False).union(cq.Workplane("XY").box(5, 26, 34, centered=False))
    part = part.edges(cq.selectors.NearestToPointSelector((5.0, 13.0, 5.0))).fillet(4)
    part = part.edges(cq.selectors.NearestToPointSelector((44.0, 13.0, 5.0))).fillet(2)
    part = part.edges(cq.selectors.NearestToPointSelector((0.0, 13.0, 34.0))).fillet(2)
    for x, y in ((30, 7), (30, 19)):
        part = part.cut(cq.Solid.makeCylinder(2.7, 5, cq.Vector(x, y, 0), cq.Vector(0, 0, 1)))
    return part.cut(cq.Solid.makeCylinder(2.7, 5, cq.Vector(0, 13, 24), cq.Vector(1, 0, 0)))


def cable_clip():
    ring = cq.Workplane("XY").circle(9).circle(6).extrude(8)
    mouth = cq.Workplane("XY").center(0, 8).rect(7, 6).extrude(8)
    tab = cq.Workplane("XY").center(0, -9.5).rect(32, 3).extrude(8)
    part = ring.cut(mouth).union(tab)
    for x in (-11, 11):
        part = part.cut(cq.Solid.makeCylinder(1.7, 6, cq.Vector(x, -12.5, 4), cq.Vector(0, 1, 0)))
    return part


def write_obj(workplane, rel, tolerance, angular):
    verts, tris = workplane.val().tessellate(tolerance, angular)
    lines = ["# Cable clip, millimetres: generated by script/landing/make_samples.py", "o cable_clip"]
    lines += [f"v {v.x:.3f} {v.y:.3f} {v.z:.3f}" for v in verts]
    lines += [f"f {a + 1} {b + 1} {c + 1}" for a, b, c in tris]
    put(rel, "\n".join(lines) + "\n")

def box_side_lbrn2():
    pts = []
    for i in range(12):                      # bottom edge, left to right: fingers 3 mm deep
        y = 0 if i % 2 == 0 else 3
        pts += [(i * 10, y), ((i + 1) * 10, y)]
    for i in reversed(range(12)):            # top edge, right to left
        y = 70 if i % 2 == 0 else 67
        pts += [((i + 1) * 10, y), (i * 10, y)]
    verts = "".join(f"V{x:g} {y:g}c0x1c1x1" for x, y in pts)
    holes = []
    for row in range(4):
        for col in range(9):
            x = 24 + col * 9 + (4.5 if row % 2 else 0)
            y = 20 + row * 10
            holes.append(f'    <Shape Type="Ellipse" CutIndex="1" Rx="3" Ry="3">\n'
                         f"        <XForm>1 0 0 1 {x:g} {y:g}</XForm>\n"
                         f"    </Shape>")
    return ('<?xml version="1.0" encoding="UTF-8"?>\n'
            '<LightBurnProject AppVersion="1.6.00" FormatVersion="1" MaterialHeight="3">\n'
            '    <CutSetting type="Cut">\n        <index Value="0"/>\n        <name Value="C00"/>\n'
            '        <color Value="255"/>\n        <speed Value="20"/>\n        <maxPower Value="80"/>\n    </CutSetting>\n'
            '    <CutSetting type="Cut">\n        <index Value="1"/>\n        <name Value="C01"/>\n'
            '        <color Value="65280"/>\n        <speed Value="20"/>\n        <maxPower Value="80"/>\n    </CutSetting>\n'
            '    <Shape Type="Path" CutIndex="0">\n        <XForm>1 0 0 1 0 0</XForm>\n'
            f"        <VertList>{verts}</VertList>\n        <PrimList>LineClosed</PrimList>\n    </Shape>\n"
            + "\n".join(holes) + "\n</LightBurnProject>\n")


def coaster_svg():
    rays = []
    n = 24
    for i in range(n):
        a0 = 2 * math.pi * i / n
        a1 = a0 + math.pi / n
        am = (a0 + a1) / 2
        p = [(50 + 13 * math.cos(a0), 50 + 13 * math.sin(a0)), (50 + 38 * math.cos(am), 50 + 38 * math.sin(am)),
             (50 + 13 * math.cos(a1), 50 + 13 * math.sin(a1))]
        rays.append("M" + " L".join(f"{x:.2f} {y:.2f}" for x, y in p) + " Z")
    ring = "M6 50 a44 44 0 1 0 88 0 a44 44 0 1 0 -88 0 Z M9 50 a41 41 0 1 0 82 0 a41 41 0 1 0 -82 0 Z"
    return ('<?xml version="1.0" encoding="UTF-8"?>\n'
            '<svg xmlns="http://www.w3.org/2000/svg" width="100mm" height="100mm" viewBox="0 0 100 100">\n'
            "  <title>Coaster, 96 mm: engrave the black, cut the red</title>\n"
            '  <g fill="#1b1c19">\n'
            f'    <path d="{" ".join(rays)}"/>\n'
            f'    <path fill-rule="evenodd" d="{ring}"/>\n'
            '    <circle cx="50" cy="50" r="9"/>\n'
            "  </g>\n"
            '  <circle cx="50" cy="50" r="4" fill="#ffffff"/>\n'
            '  <circle cx="50" cy="50" r="48" fill="none" stroke="#e10600" stroke-width="0.4"/>\n'
            "</svg>\n")


def dxf(entities):
    head = ["0", "SECTION", "2", "HEADER", "9", "$INSUNITS", "70", "4", "0", "ENDSEC",
            "0", "SECTION", "2", "TABLES", "0", "TABLE", "2", "LAYER",
            "0", "LAYER", "2", "Cut", "62", "1",
            "0", "LAYER", "2", "Engrave", "62", "5",
            "0", "ENDTAB", "0", "ENDSEC", "0", "SECTION", "2", "ENTITIES"]
    return "\n".join(head + entities + ["0", "ENDSEC", "0", "EOF"]) + "\n"


def f3(v):
    return f"{v:.3f}"


def lwpoly(layer, pts):
    e = ["0", "LWPOLYLINE", "8", layer, "90", str(len(pts)), "70", "1"]
    for x, y in pts:
        e += ["10", f3(x), "20", f3(y)]
    return e


def circle(layer, x, y, r):
    return ["0", "CIRCLE", "8", layer, "10", f3(x), "20", f3(y), "30", "0", "40", f3(r)]


def arc(layer, x, y, r, a0, a1):
    return ["0", "ARC", "8", layer, "10", f3(x), "20", f3(y), "30", "0", "40", f3(r), "50", f3(a0), "51", f3(a1)]


def line(layer, x0, y0, x1, y1):
    return ["0", "LINE", "8", layer, "10", f3(x0), "20", f3(y0), "30", "0", "11", f3(x1), "21", f3(y1), "31", "0"]


def slot(layer, x, y, length, width):
    r = width / 2
    return (line(layer, x, y + r, x + length, y + r) + line(layer, x, y - r, x + length, y - r)
            + arc(layer, x, y, r, 90, 270) + arc(layer, x + length, y, r, 270, 90))


def mount_plate_dxf():
    ents = lwpoly("Cut", rounded_rect(0, 0, 90, 50, 5))
    for x, y in ((7, 7), (83, 7), (7, 43), (83, 43)):
        ents += circle("Cut", x, y, 2.2)
    for y in (16, 34):
        ents += slot("Cut", 17, y, 16, 5)
    ents += lwpoly("Cut", rounded_rect(48, 13, 30, 24, 3))
    ents += line("Engrave", 21, 25, 29, 25) + line("Engrave", 25, 21, 25, 29)
    return dxf(ents)


def drawer_label_mage():
    def path(op, pts):
        verts = "".join(f"V{x:.2f} {y:.2f}c0x1c1x1" for x, y in pts)
        return (f'    <Shape Type="Path" OpIndex="{op}" LayerIndex="{op}">\n        <XForm>1 0 0 1 0 0</XForm>\n'
                f"        <VertList>{verts}</VertList>\n        <PrimList>LineClosed</PrimList>\n    </Shape>")

    def hole(x, y):
        return (f'    <Shape Type="Ellipse" OpIndex="0" LayerIndex="0" Rx="2.5" Ry="2.5">\n'
                f"        <XForm>1 0 0 1 {x} {y}</XForm>\n    </Shape>")

    def hexagon(cx, cy, r):
        return [(cx + r * math.cos(math.pi / 6 + k * math.pi / 3), cy + r * math.sin(math.pi / 6 + k * math.pi / 3)) for k in range(6)]

    def op(kind, shapes, depth):
        return (f'    <Operation type="{kind}" Shapes="{shapes}">\n        <ToolDef>\n'
                '            <name Value="3 mm flat end mill"/>\n            <type Value="End Mill"/>\n'
                '            <index Value="0"/>\n            <diameter Value="3.0"/>\n        </ToolDef>\n'
                f'        <finalDepth Value="{depth}"/>\n        <name Value="{kind}"/>\n    </Operation>')

    shapes = [path(0, rounded_rect(0, 0, 100, 40, 6)), hole(8, 20), hole(92, 20)]
    shapes += [path(1, hexagon(26 + 24 * i, 20, 9)) for i in range(3)]
    return ('<?xml version="1.0" encoding="UTF-8"?>\n'
            '<MillMageProject AppVersion="0.8.01" DeviceName="desktop router" FormatVersion="1" '
            'MaterialHeight="6" MirrorX="False" MirrorY="False">\n'
            + op("Profile", "0 1 2", 6) + "\n" + op("Pocket", "3 4 5", 2) + "\n"
            + "\n".join(shapes) + "\n</MillMageProject>\n")

def gerber_zip():
    def c(v):
        return str(round(v * 1_000_000))

    def layer(apertures, body):
        head = ["G04 Desk lamp driver board, generated by script/landing/make_samples.py*",
                "%FSLAX46Y46*%", "%MOMM*%", "%LPD*%"] + [f"%ADD{code}{spec}*%" for code, spec in apertures]
        return "\n".join(head + body + ["M02*"]) + "\n"

    def path(points):
        (x0, y0), rest = points[0], points[1:]
        return [f"X{c(x0)}Y{c(y0)}D02*"] + [f"X{c(x)}Y{c(y)}D01*" for x, y in rest]

    def flashes(points):
        return [f"X{c(x)}Y{c(y)}D03*" for x, y in points]

    def rect(x0, y0, x1, y1):
        return [(x0, y0), (x1, y0), (x1, y1), (x0, y1), (x0, y0)]

    def ring(cx, cy, r, n=20):
        return [(cx + r * math.cos(2 * math.pi * k / n), cy + r * math.sin(2 * math.pi * k / n)) for k in range(n + 1)]

    dip = [(14 + 2.54 * i, 11.19) for i in range(4)] + [(14 + 2.54 * (3 - i), 18.81) for i in range(4)]  # pins 1-8
    mosfet = [(33 + 2.54 * i, 22.0) for i in range(3)]                                                 # G D S
    terminal = [(6.0, 11.0), (6.0, 19.0)]                                                              # - +
    led = [(43.0, 8.0), (45.54, 8.0)]
    button = [(26.0, 27.0), (31.0, 27.0)]
    round_pads = dip[1:] + mosfet[1:] + led[1:] + button
    square_pads = [dip[0], mosfet[0], led[0]]

    top_traces = [
        [terminal[1], (12.0, 19.0), dip[7]],                               # + to pin 8 (VCC)
        [terminal[0], (8.0, 11.0), (8.0, 3.0), (38.08, 3.0), mosfet[2]],   # - to the source
        [dip[3], (21.62, 3.0)],                                            # pin 4 (GND) to -
        [dip[4], (27.0, 18.81), (27.0, 22.0), mosfet[0]],                  # pin 5 (PB0) to the gate
        [dip[6], (16.54, 27.0), button[0]],                                # pin 7 (PB2) to the button
    ]
    bottom_traces = [[mosfet[1], (35.54, 14.0), (43.0, 14.0), led[0]]]     # drain to the LED
    silk = [rect(12.6, 12.6, 23.0, 17.4), rect(31.3, 19.6, 39.8, 24.4), rect(3.0, 7.5, 9.0, 22.5),
            rect(24.3, 25.2, 32.7, 28.8), ring(44.27, 8.0, 3.0), [(12.6, 14.2), (13.4, 15.0), (12.6, 15.8)]]

    copper_apertures = [(10, "C,0.500"), (11, "C,1.700"), (12, "R,1.700X1.700"), (13, "C,2.600")]
    mask_apertures = [(11, "C,1.800"), (12, "R,1.800X1.800"), (13, "C,2.700")]

    def pads():
        return ["D11*"] + flashes(round_pads) + ["D12*"] + flashes(square_pads) + ["D13*"] + flashes(terminal)

    top = layer(copper_apertures, ["D10*"] + sum((path(t) for t in top_traces), []) + pads())
    bottom = layer(copper_apertures, ["D10*"] + sum((path(t) for t in bottom_traces), []) + pads())
    mask = layer(mask_apertures, pads())
    silkscreen = layer([(15, "C,0.150")], ["D15*"] + sum((path(o) for o in silk), []))
    edge = layer([(16, "C,0.100")], ["D16*"] + path(rect(0, 0, 50, 30)))
    drill = "\n".join(["M48", "METRIC", "T1C0.800", "T2C1.300", "%", "G90", "G05", "T1"]
                      + [f"X{x:.3f}Y{y:.3f}" for x, y in round_pads + square_pads]
                      + ["T2"] + [f"X{x:.3f}Y{y:.3f}" for x, y in terminal] + ["M30"]) + "\n"
    files = {"lamp-F_Cu.gtl": top, "lamp-B_Cu.gbl": bottom, "lamp-F_Mask.gts": mask, "lamp-B_Mask.gbs": mask,
             "lamp-F_SilkS.gto": silkscreen, "lamp-Edge_Cuts.gm1": edge, "lamp.drl": drill}
    buf = BytesIO()
    with zipfile.ZipFile(buf, "w") as z:
        for name, text in files.items():
            info = zipfile.ZipInfo(f"lamp-gerbers/{name}", date_time=(2026, 10, 16, 0, 0, 0))
            info.compress_type = zipfile.ZIP_DEFLATED
            z.writestr(info, text)
    return buf.getvalue()

def assembly_pdf():
    k = 72 / 25.4 * 2          # points per millimetre of part, at 2:1
    ox, oy = 90.0, 200.0       # the plate's lower-left corner on the page

    def text(x, y, size, s):
        s = s.replace("\\", "\\\\").replace("(", "\\(").replace(")", "\\)")
        return ["BT", f"/F1 {size} Tf", f"{x:.2f} {y:.2f} Td", f"({s}) Tj", "ET"]

    def arrow(x, y, dx, dy):    # a filled arrowhead with its tip at (x, y), pointing along (dx, dy)
        bx, by, px, py = x - dx * 8, y - dy * 8, -dy * 2.5, dx * 2.5
        return [f"{x:.2f} {y:.2f} m {bx + px:.2f} {by + py:.2f} l {bx - px:.2f} {by - py:.2f} l f"]

    def circle_ops(cx, cy, r):
        m = 0.5523 * r
        return [f"{cx + r:.2f} {cy:.2f} m",
                f"{cx + r:.2f} {cy + m:.2f} {cx + m:.2f} {cy + r:.2f} {cx:.2f} {cy + r:.2f} c",
                f"{cx - m:.2f} {cy + r:.2f} {cx - r:.2f} {cy + m:.2f} {cx - r:.2f} {cy:.2f} c",
                f"{cx - r:.2f} {cy - m:.2f} {cx - m:.2f} {cy - r:.2f} {cx:.2f} {cy - r:.2f} c",
                f"{cx + m:.2f} {cy - r:.2f} {cx + r:.2f} {cy - m:.2f} {cx + r:.2f} {cy:.2f} c", "S"]

    x1, y1 = ox + 80 * k, oy + 40 * k
    hx, hy, hr = ox + 40 * k, oy + 20 * k, 5 * k
    ops = ["1 J 1 j", "0.6 w", "20 20 802 555 re S",
           "562 20 260 70 re S", "562 55 m 822 55 l S", "692 20 m 692 55 l S"]
    ops += text(570, 68, 13, "DESK LAMP - MOUNTING PLATE")
    ops += text(570, 33, 9, "Scale 2:1   Units mm") + text(700, 33, 9, "3 mm birch ply, laser cut")
    ops += ["1.2 w", f"{ox:.2f} {oy:.2f} {80 * k:.2f} {40 * k:.2f} re S"] + circle_ops(hx, hy, hr)
    ops += ["0.4 w [6 3 1 3] 0 d", f"{hx - 9 * k:.2f} {hy:.2f} m {hx + 9 * k:.2f} {hy:.2f} l S",
            f"{hx:.2f} {hy - 9 * k:.2f} m {hx:.2f} {hy + 9 * k:.2f} l S", "[] 0 d"]
    ops += [f"{ox:.2f} {oy - 4:.2f} m {ox:.2f} {oy - 36:.2f} l S", f"{x1:.2f} {oy - 4:.2f} m {x1:.2f} {oy - 36:.2f} l S",
            f"{ox:.2f} {oy - 30:.2f} m {x1:.2f} {oy - 30:.2f} l S"]
    ops += arrow(ox, oy - 30, -1, 0) + arrow(x1, oy - 30, 1, 0) + text((ox + x1) / 2 - 7, oy - 26, 11, "80")
    ops += [f"{x1 + 4:.2f} {oy:.2f} m {x1 + 36:.2f} {oy:.2f} l S", f"{x1 + 4:.2f} {y1:.2f} m {x1 + 36:.2f} {y1:.2f} l S",
            f"{x1 + 30:.2f} {oy:.2f} m {x1 + 30:.2f} {y1:.2f} l S"]
    ops += arrow(x1 + 30, oy, 0, -1) + arrow(x1 + 30, y1, 0, 1) + text(x1 + 36, (oy + y1) / 2 - 4, 11, "40")
    lx, ly = hx + hr * 0.7071, hy + hr * 0.7071
    tx, ty = hx + 70, y1 + 40
    d = math.hypot(lx - tx, ly - ty)
    ops += [f"{tx:.2f} {ty:.2f} m {lx:.2f} {ly:.2f} l S"] + arrow(lx, ly, (lx - tx) / d, (ly - ty) / d)
    ops += text(tx + 4, ty + 2, 11, "\xd8" + "10 through")

    stream = "\n".join(ops).encode("latin-1")
    objs = [b"<< /Type /Catalog /Pages 2 0 R >>",
            b"<< /Type /Pages /Kids [3 0 R] /Count 1 >>",
            b"<< /Type /Page /Parent 2 0 R /MediaBox [0 0 842 595] /Contents 4 0 R "
            b"/Resources << /Font << /F1 5 0 R >> >> >>",
            b"<< /Length %d >>\nstream\n" % len(stream) + stream + b"\nendstream",
            b"<< /Type /Font /Subtype /Type1 /BaseFont /Helvetica /Encoding /WinAnsiEncoding >>"]
    out = bytearray(b"%PDF-1.4\n%\xe2\xe3\xcf\xd3\n")
    offsets = []
    for i, body in enumerate(objs, 1):
        offsets.append(len(out))
        out += b"%d 0 obj\n" % i + body + b"\nendobj\n"
    xref = len(out)
    out += b"xref\n0 %d\n0000000000 65535 f \n" % (len(objs) + 1)
    for off in offsets:
        out += b"%010d 00000 n \n" % off
    out += b"trailer\n<< /Size %d /Root 1 0 R >>\nstartxref\n%d\n%%%%EOF\n" % (len(objs) + 1, xref)
    return bytes(out)


LAMP_INO = """// Desk lamp dimmer: one button steps the LED strip through five brightness levels, and a long
// press turns it off. An ATtiny85 on the lamp's driver board (../pcb), the MOSFET's gate on PB0.

const uint8_t LED_PIN = 0;      // PB0, PWM, drives the MOSFET gate
const uint8_t BUTTON_PIN = 2;   // PB2, to ground, internal pull-up
const uint8_t LEVELS[] = { 0, 16, 48, 112, 255 };
const unsigned long LONG_PRESS_MS = 600;

uint8_t level = 0;

void fadeTo(uint8_t target) {
  static uint8_t current = 0;
  while (current != target) {
    current += current < target ? 1 : -1;
    analogWrite(LED_PIN, current);
    delay(2);
  }
}

void setup() {
  pinMode(LED_PIN, OUTPUT);
  pinMode(BUTTON_PIN, INPUT_PULLUP);
  analogWrite(LED_PIN, LEVELS[level]);
}

void loop() {
  if (digitalRead(BUTTON_PIN) == HIGH) return;

  unsigned long pressed = millis();
  while (digitalRead(BUTTON_PIN) == LOW) delay(5);
  bool longPress = millis() - pressed >= LONG_PRESS_MS;

  level = longPress ? 0 : (level + 1) % sizeof(LEVELS);
  fadeTo(LEVELS[level]);
}
"""
```

```ruby
#!/usr/bin/env ruby
# The landing's four feature crops (docs/superpowers/specs/2026-10-16-landing-format-wall-design.md
# section 3): the app, photographed. Drives headless Chrome at device pixel ratio 2 against a running
# Tinkerex whose demo is seeded from db/seeds/demo, signs in with Try the demo, and writes one
# 1120x700 JPEG per crop into app/assets/images/landing. The demo banner is removed before each
# capture -- it is the public demo's chrome, not the app's -- and NOTHING ELSE on the page is touched.
#
#   bundle exec ruby script/landing/capture_crops.rb http://localhost:8080
#
# Needs `vips` on PATH (Homebrew's) for the JPEG encode. Retake the crops whenever the pages they
# show move; never edit the images by hand.
require "base64"
require "open3"
require "selenium-webdriver"
require "tmpdir"

BASE = ARGV.fetch(0) { abort "usage: capture_crops.rb BASE_URL" }.chomp("/")
OUT = File.expand_path("../../app/assets/images/landing", __dir__)
WIDTH = 1120 # the <img> width/height in app/views/landings/show.html.erb
HEIGHT = 700
ASPECT = WIDTH.fdiv(HEIGHT)

# name => [the page (a file found by name, or a path), the element to frame, how to frame it, ready?]
#   expand -- the whole element, widened or heightened around its centre to 16:10
#   top    -- the element's full width, 16:10 from its top edge
CROPS = {
  "viewer" => [ [ :file, "base.stl" ], ".model-viewer", "expand",
                "(document.querySelector('.model-viewer-dims')?.textContent || '').trim().length > 0" ],
  "measure" => [ [ :file, "box-side.lbrn2" ], ".measure-view", "expand",
                 "(document.querySelector('.measure-stage')?.childElementCount || 0) > 0" ],
  "project" => [ [ :path, "/projects/desk-lamp" ], "main#main", "top", "!!document.querySelector('.page-head')" ],
  "boxes" => [ [ :path, "/tools/boxes" ], "main#main", "top", "!!document.querySelector('main svg, main canvas')" ]
}.freeze

FRAME_JS = <<~JS.freeze
  const [selector, frame, aspect] = arguments;
  const r = document.querySelector(selector).getBoundingClientRect();
  let x = r.left + scrollX, y = r.top + scrollY, w = r.width, h = r.height;
  if (frame === "expand" && w / h < aspect) { const nw = h * aspect; x -= (nw - w) / 2; w = nw; }
  else if (frame === "expand") { const nh = w / aspect; y -= (nh - h) / 2; h = nh; }
  return { x: Math.max(0, x), y: Math.max(0, y), width: w, height: w / aspect, scale: 1 };
JS

options = Selenium::WebDriver::Chrome::Options.new(args: %w[--headless=new --window-size=1280,800 --hide-scrollbars])
driver = Selenium::WebDriver.for(:chrome, options:)
driver.execute_cdp("Emulation.setDeviceMetricsOverride", width: 1280, height: 800, deviceScaleFactor: 2, mobile: false)
wait = Selenium::WebDriver::Wait.new(timeout: 90)

begin
  driver.navigate.to "#{BASE}/"
  wait.until { driver.find_elements(xpath: "//button[normalize-space()='Try the demo']").any? }.first.click
  wait.until { driver.find_elements(css: "aside.rail").any? }

  CROPS.each do |name, (target, selector, frame, ready)|
    if target.first == :file
      driver.navigate.to "#{BASE}/files?q=#{target.last}"
      link = wait.until do
        driver.find_elements(xpath: "//main//a[contains(@href,'/files/')][contains(normalize-space(.), \"#{target.last}\")]").first
      end
      driver.navigate.to link.attribute("href")
    else
      driver.navigate.to "#{BASE}#{target.last}"
    end
    wait.until { driver.execute_script("return #{ready}") }
    sleep 3 # a WebGL frame, the Measure stage and an addon bundle all finish drawing after "ready"
    driver.execute_script("document.querySelector('.demo-banner')?.remove(); window.scrollTo(0, 0)")
    clip = driver.execute_script(FRAME_JS, selector, frame, ASPECT)
    data = driver.execute_cdp("Page.captureScreenshot", format: "png", clip:, captureBeyondViewport: true)["data"]

    Dir.mktmpdir do |dir|
      png = File.join(dir, "#{name}.png")
      File.binwrite(png, Base64.decode64(data))
      out = File.join(OUT, "#{name}.jpg")
      _, err, status = Open3.capture3("vips", "thumbnail", png, "#{out}[Q=82,strip]", WIDTH.to_s,
                                      "--height", HEIGHT.to_s, "--size", "force")
      abort "vips failed for #{name}: #{err}" unless status.success?
      puts "wrote #{out}"
    end
  end
ensure
  driver.quit
end
```

```ruby
# THE LANDING IN A BROWSER (second pass, 2026-10-16). What a request test cannot see: that
# `landing-main` beats the layout's 440px auth column (a computed width), that the wall stands beside
# the pitch on a desktop and under it on a phone, that every tile actually LOADED (an <img> whose
# bytes do not decode is a broken box a request test passes over), and that nothing scrolls sideways
# at 375px (design-system.md rule 11). The viewport is set through CDP: headless Chrome refuses a
# window narrower than 500px.
class LandingSystemTest < ApplicationSystemTestCase
  setup do
    @root = use_fresh_share_library!
    @prior_demo = ENV["DEMO_ACCOUNT_EMAIL"]
    ENV["DEMO_ACCOUNT_EMAIL"] = "demo@example.com"
    User.create!(email: "demo@example.com", password: SecureRandom.base58(32), confirmed_at: Time.current, handle: "demo")
  end

  teardown do
    @prior_demo.nil? ? ENV.delete("DEMO_ACCOUNT_EMAIL") : ENV["DEMO_ACCOUNT_EMAIL"] = @prior_demo
    FileLayer.reset!
    FileUtils.remove_entry(@root) if @root&.exist?
  end

  def rect(selector)
    page.evaluate_script("(r => ({ left: r.left, right: r.right, top: r.top, bottom: r.bottom, width: r.width }))" \
                         "(document.querySelector(#{selector.to_json}).getBoundingClientRect())")
  end

  test "the wall stands beside the pitch at desktop width, every tile loads, and a phone stacks it without sideways scroll" do
    visit "/"
    assert_selector ".landing-hero h1"
    assert_selector ".landing-wall img", count: Tinkerex::Landing::TILES.size

    width = rect("main#main")["width"]
    assert_operator width, :>, 900, "main is #{width}px wide: the landing is still inside the 440px auth column"
    assert_operator rect(".landing-pitch")["right"], :<=, rect(".landing-wall")["left"],
                    "the wall should stand right of the pitch at desktop width"

    # LOADED, NOT MERELY PRESENT: a tile whose bytes do not decode has naturalWidth 0.
    widths = page.evaluate_async_script(<<~JS)
      const done = arguments[arguments.length - 1];
      const imgs = [...document.querySelectorAll('.landing-wall img')];
      Promise.all(imgs.map(i => i.complete ? null : new Promise(r => { i.onload = i.onerror = r })))
        .then(() => done(imgs.map(i => i.naturalWidth)));
    JS
    assert widths.all?(&:positive?), "a wall tile did not load: naturalWidths #{widths.inspect}"

    page.driver.browser.execute_cdp("Emulation.setDeviceMetricsOverride",
                                    width: 375, height: 812, deviceScaleFactor: 1, mobile: false)
    begin
      visit "/"
      assert_selector ".landing-hero h1"
      assert page.evaluate_script("document.documentElement.scrollWidth <= window.innerWidth"),
             "the landing scrolls sideways at 375px (scrollWidth #{page.evaluate_script('document.documentElement.scrollWidth')})"
      assert_operator rect(".landing-wall")["top"], :>=, rect(".landing-pitch")["bottom"],
                      "the wall should stack under the pitch on a phone"
    ensure
      page.driver.browser.execute_cdp("Emulation.clearDeviceMetricsOverride")
    end
  end
```
